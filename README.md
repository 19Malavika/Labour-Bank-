# Labour Bank
A mobile application that connects skilled workers with customers in Ettumanoor Block Panchayat.


## 📌 Project Overview

**Labour Bank** is a mobile application developed to bridge the gap between skilled workers and customers in the Ettumanoor Block Panchayat. The application provides a secure and user-friendly platform where customers can easily find skilled workers such as plumbers, electricians, carpenters, painters, cleaners, AC technicians, and more.

The project aims to improve employment opportunities for local workers while making it easier for customers to access reliable home maintenance services.

---

## 🎯 Problem Statement

Many skilled workers in Ettumanoor Block Panchayat rely on word-of-mouth recommendations and local contacts to find work. This limits their employment opportunities and affects their income and job stability.

At the same time, customers often struggle to find trustworthy workers because there is no centralized platform to compare services, check worker profiles, view ratings, or verify availability.

---

## 💡 Solution

Labour Bank is designed to digitally connect customers and skilled workers through a single platform.

The application enables customers to:

* Search for skilled workers by category
* View worker profiles
* Check ratings and reviews
* View availability
* Contact workers directly
* Book services conveniently

Workers can:

* Create and manage their profiles
* Display their skills and experience
* Receive service requests
* Communicate with customers
* Increase their employment opportunities
